# 📚 VLM 지능형 서고 관리 자동화 플랫폼

본 프로젝트는 자율주행 로봇(Edge)의 **Vision AI**와 중앙 서버(Cloud)의 **데이터 융합 알고리즘**을 이용하여, 도서관 서가의 도서 상태(오배열, 누락, 누움, 뒤집힘 등)를 실시간으로 탐지하고 관리자에게 보고하는 **End-to-End 자동화 시스템**입니다.

## 🌟 주요 기능
- **Vision AI 이상 탐지 (Edge)**: YOLOv8과 ResNet18을 활용하여 책등을 탐지하고, 가로/세로 분리 및 코사인 유사도를 통해 책의 물리적 이상 상태(누움, 뒤집힘, 종이 끼임 등)를 판별합니다.
- **교차 검증 분석기 (Backend)**: Vision 데이터와 RFID 데이터를 기존 대출 시스템(ILS) 정답지와 교차 검증하여 논리적 이상 상태(오배열, 오배가, 분실)를 융합 판별합니다.
- **원클릭 파이프라인**: 엣지 컴퓨팅부터 중앙 DB 적재, 대시보드 출력까지 모든 과정이 단 하나의 스크립트(`run_master.py`)로 자동 실행됩니다.
- **실시간 웹 대시보드**: 별도의 프론트엔드 프레임워크 없이 작동하는 경량화된 웹 대시보드를 통해 융합 분석 결과를 실시간으로 모니터링할 수 있습니다.

## 🛠️ 설치 및 세팅 방법

### 1. 환경 구축 및 패키지 설치
Python 3.10 이상의 환경에서 아래 패키지들을 설치해 주세요.
```bash
pip install fastapi uvicorn pydantic mysql-connector-python requests
pip install ultralytics torch torchvision pandas rembg[cpu]
```

### 2. 데이터베이스(MySQL) 세팅
1. 로컬 MySQL에 `library_ai_db` 라는 이름의 데이터베이스를 생성합니다.
2. `backend/main.py`와 `reset_db.py` 내부의 `DB_CONFIG`를 본인의 DB 환경(아이디/비밀번호 등)에 맞게 수정해 주세요.

### 3. 🚨 [주의사항] AI 모델 파일 (Git LFS)
본 저장소를 클론(`git clone`)할 때 Git LFS가 설치되어 있지 않으면 모델 파일(`ach/model/model_v2.pt`)이 정상적으로 다운로드되지 않습니다(1KB 텍스트로 다운됨). 
만약 실행 중 `_pickle.UnpicklingError`가 발생한다면, **깃허브 웹페이지에서 해당 `.pt` 파일을 수동으로 다운로드하여 덮어쓰기** 해주세요!

## 🚀 전체 파이프라인 실행 방법 (테스트)

팀장님이 구축한 통합 파이프라인을 통해 모든 과정을 한 번에 테스트할 수 있습니다.

**터미널 1: 백엔드 서버 가동**
먼저 클라우드 서버(FastAPI)를 실행시켜 둡니다.
```bash
cd backend
uvicorn main:app --reload
```

**터미널 2: 원클릭 마스터 스크립트 실행**
http://127.0.0.1:8000/dashboard 접속

### 💡 파이프라인 작동 순서
1. `FeatureAnalysis.py` 작동 ➔ 서가 사진에서 책등 크롭 및 특징 추출
2. `MakeResult.py` 작동 ➔ 추출된 데이터를 바탕으로 상태(누움, 뒤집힘 등) 분류
3. `test_full_pipeline.py` 작동 ➔ 결과를 서버로 전송 및 RFID와 융합 분석
4. **결과 확인** ➔ 스크립트 종료 후, **자동으로 브라우저 창이 열리며 `dashboard.html` 대시보드에 최종 분석 결과가 표출됩니다!**

## 🧹 디버깅 팁 (DB 초기화)
테스트를 여러 번 진행하여 DB에 찌꺼기 데이터가 많이 쌓였다면, 초기화 스크립트를 사용하여 DB를 깨끗하게 비울 수 있습니다.
```bash
python reset_db.py
```
실행 후 대시보드를 새로고침하면 모든 데이터가 `0`으로 리셋됩니다.
